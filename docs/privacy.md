# Privacidad y limitaciones

- No se guarda audio crudo; solo se almacena la energía, niveles agregados y puntos temporales.
- El historial de sesiones queda en Room bajo control local del dispositivo.
- Se conserva información del trabajador/evaluador, metadatos del dispositivo y datos de la calibración no certificados.
- La aplicación no sustituye ni reemplaza la validación metrológica formal.
