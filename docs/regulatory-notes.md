# Limitaciones regulatorias

Este proyecto no constituye una certificación de instrumento ni una afirmación de cumplimiento formal con IEC, ISO, NIOSH u otras normativas. La dosimetría ocupacional requiere comprobación metrológica, trazabilidad, procedimiento y validación del sistema de medición. La aplicación se presenta como herramienta asistencial y de análisis en contexto profesional, no como un equipo de medición certificado.
